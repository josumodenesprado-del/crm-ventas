# Versiones del CRM VelixAI

Historial de versiones de producción. Cada versión corresponde a un tag en GitHub y a un deployment en Vercel.

## v1.0 — 18/09/2026 (versión base actual)
- Gestión de leads: crear, editar, borrar, buscar, exportar Excel.
- Pipeline con arrastrar y soltar + buscador por negocio (nombre, empresa, teléfono, ciudad).
- La tarjeta editada (mover, notas, fecha) salta a primera posición.
- Notas con historial en la ficha del Pipeline.
- Fecha de seguimiento sin mover estado.
- Auto-refresh cada 30 segundos + botón actualizar manual.
- Dashboard, usuarios y roles (admin/vendedor), actividad reciente.
- Login con logo VelixAI.
